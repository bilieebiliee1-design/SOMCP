# SOMCP 1.0.11

本发布说明仅包含 `v1.0.10..v1.0.11` 的增量变化。

## 更新内容

- 修复 MCP 无法打开 APK 内 SO 的问题：重写来源匹配，新增纯函数解析 `apk:<相对路径>!lib/<abi>/x.so`、绝对路径 `App.apk!entry`、`content://apk/` 嵌套路径与裸 `lib/...` entry 四种等价写法，按 apkPath/apkEntry 语义匹配。
- 修复 1.0.10 引入的局域网链接不显示回归：现始终展示回环、局域网与可路由地址，绑定地址仅决定实际监听范围。
- APK 内 SO 引用无法解析时返回更明确的提示；APK 嵌入引用不再被误判为越界文件路径。
- 新增运行时溯源信息：MCP `initialize`、健康检查与"关于"页固定输出 GPL-3.0、上游官方仓库、版权与再分发义务。
- 强化开源合规：新增 `NOTICE`，README 与关于页以《著作权法》《计算机软件保护条例》及 GPL 司法案例强化再分发义务与侵权告知。
- 新增维权材料 `docs/legal`：中英文 GPL 侵权告知函、论坛/网盘投诉与 GitHub DMCA 模板、证据固定清单。
- 新增 APK 内 SO 引用解析单元测试。

## 验证

- 完整 JVM 单元测试。
- Debug/Release Kotlin 编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

# SOMCP 1.0.16

本发布说明仅包含 `v1.0.15..v1.0.16` 的增量变化。

## 更新内容

- 修复在开启公网隧道后点击停止服务会卡死的问题：停止路径改为先同步标记停止，再异步回收 cloudflared，避免主线程等待退出。
- 收紧快速隧道注册流程，停止时会中断仍在进行的请求，避免旧注册流程阻塞停止操作。
- 保留端口占用提示与原有启动失败反馈，避免把端口冲突误表现为无响应卡死。

## 验证

- JVM 单元测试。
- Debug Kotlin、Java 与四 ABI 原生编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

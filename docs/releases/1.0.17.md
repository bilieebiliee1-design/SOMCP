# SOMCP 1.0.17

本发布说明仅包含 `v1.0.16..v1.0.17` 的增量变化。

## 更新内容

- 支持多个并发 APK MCP 桥接（MT Manager 与 NP Manager 同时连接）。
- 修复 `ApkMcpBridge.probeUrl()` 在桥接离线时仍保存配置的问题，新增离线桥接后可稍后重试。
- 新增一次性迁移，预填 MT Manager（http://127.0.0.1:8787/mcp）与 NP Manager（http://127.0.0.1:8788/mcp）默认桥接地址。
- 备份/恢复支持基于 Argon2id（3 次迭代、64 MiB 内存）密钥派生 + AES-256-GCM 的可选加密；UI 提供加密开关与密码/确认输入，并在忘记密码将丢失数据时给出警告；导入时按 magic header 自动识别加密文件并提示输入密码；未设密码时默认仍为明文 JSON 导出。
- 新增更多 GitHub 下载加速镜像源。
- 调整 CI：从 test-v6 移除 pull_request 触发，PR 默认使用 test-v7；撤销临时上传调试 APK 产物的改动。

## 验证

- JVM 单元测试。
- Debug Kotlin、Java 与四 ABI 原生编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

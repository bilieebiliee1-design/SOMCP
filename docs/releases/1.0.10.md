# SOMCP 1.0.10

本发布说明仅包含 `v1.0.9..v1.0.10` 的增量变化。

## 更新内容

- 复审并收敛 Cloudflare 永久隧道的公开暴露流程，补齐公网主机名/URL 提示、启动前鉴权和状态展示。
- 强化 Cloudflare 永久隧道错误识别，遇到认证或发布路由问题时终止重连并提示修复 token 与 Cloudflare 配置。
- 收紧 `app_config` 的安全字段写入范围，避免远程 patch 直接修改绑定地址、鉴权开关和隧道 token。
- 改进 SO/ELF 路径解析，增加对 SAF 工作目录相对路径与绝对路径的精确匹配，并在越界时给出可操作错误。
- 保持 APK 流式读取与 heap 预算限制，继续阻止不在允许目录范围内的本地 APK 输入。
- 设置页与系统状态页补充公网隧道配置引导，提示 Cloudflare 发布应用路由和访问 Token 的前置条件。

## 验证

- 完整 JVM 单元测试。
- Debug Kotlin 编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

# SOMCP 1.0.13

本发布说明仅包含 `v1.0.12..v1.0.13` 的增量变化。

## 更新内容

- 修复 Rizin 原生分析并发导致的闪退：多协程并发调用 `rzFunctions` 等时，Rizin `RzCore` 非线程安全会在 `rz_core_free` 处 double-free 崩溃（Native SIGSEGV）。现将所有 `rz*` 原生入口统一串行化。
- 举一反三：为 LIEF 原生层加入相同的进程级串行锁，消除同类并发崩溃风险。
- 修复更新下载切换加速源时的竞态：切源时旧下载可能仍在写同一临时文件并触发校验/回调，导致“镜像 A 中途变 B”“A 校验完又用 B 重下”等异常。现对下载过程加互斥并在锁内复用已完成的校验结果。
- 精简单元测试至守护关键逻辑的最小集合。

## 验证

- JVM 单元测试（精简后）。
- Debug/Release Kotlin 编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

# SOMCP 1.0.18

本发布说明仅包含 `v1.0.17..v1.0.18` 的增量变化。

## 更新内容

- 移除内置 NP Manager 集成：APK MCP 桥接不再支持 NP Manager（`http://127.0.0.1:8788/mcp`，前缀 `np_*`）。删除 `ApkMcpBridge` 中的 `NP_PORT` / `NP_PREFIX`，`KNOWN_PREFIXES` 仅保留 `MT_PREFIX`；`detectPrefix` / `prefixLabel` / `autoDiscover()` 不再识别 NP；默认桥接只预填 MT Manager（http://127.0.0.1:8787/mcp）。
- 新增一次性迁移 `apkNpBridgeRemoved`：对已有安装，从桥接配置中剔除自动预填的内置 NP Manager 默认地址，确保老用户不再残留该桥接。
- `SettingsApkBridgePage`、`ToolCatalog`、`McpHttpServer` 中涉及 "NP Manager" / "np_" 的提示文案同步清理。
- Flutter 分析（`flutter_blutter`）加速：原生 Blutter 分析属确定性流程，相同输入必产生字节级一致输出。新增运行时结果缓存——以 `SHA256(libapp ‖ libflutter ‖ runner.sha256 ‖ options)` 为键，命中即复用 `results/<key>/result.json`，跳过原生分析；重复分析 / 批量分析由约 10min 降至 <1s（`backend` 字段返回 `cache`，`cacheHit=true`）。另将 `analyze()` 的 APK 解包 + ELF 解析合并为单次流程，消除原先每轮分析 2–3 次的重复解包。正确性由内容指纹缓存键与 Blutter 上游确定性共同保证；全新大型包的首次分析仍走原生流程，构建矩阵（`tools/blutter-matrix`）不变。

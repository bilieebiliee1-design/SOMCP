# SOMCP 1.0.12（紧急补丁）

本发布说明仅包含 `v1.0.11..v1.0.12` 的增量变化。

## 致歉

`1.0.10`/`1.0.11` 出于安全考虑把默认绑定收敛为 `127.0.0.1` 并默认强制开启 Token，导致部分用户升级后局域网链接不显示、连接体验变差。这是我们在默认值取舍上的失误，给你带来的不便深表歉意。本紧急补丁恢复开箱即用的默认，并一次性纠正因更新而被写入的错误配置。

## 更新内容

- 默认开启局域网访问（绑定 `0.0.0.0`）且默认不强制 Token；需要更严格保护可在设置中自行开启鉴权与回环绑定。
- 一次性纠正因 `1.0.10`/`1.0.11` 更新被强制写入的错误配置，升级后自动恢复为友好默认（只执行一次，之后尊重用户自定义）。
- Cloudflare 隧道默认不再强制 Token：仅当用户自行开启鉴权时才要求访问 Token，否则按用户意愿启动并提示公网暴露风险。
- 下载更新的 SHA-256 校验改为尽力而为：限次数、带超时，校验源不可用时降级为“已下载有效 APK 但未校验”，不再卡死或直接失败；仅在获取到校验值却不匹配时判失败。
- 更新加速线路支持手动切换：测速中或下载中点选任一线路即可立即切换加速源，解决部分线路测速快但下载慢的问题。
- 下载缓存复用更稳健，避免不必要的重复下载。

## 验证

- Debug/Release Kotlin 编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

# SOMCP 1.0.14

本发布说明仅包含 `v1.0.13..v1.0.14` 的增量变化。

## 更新内容

- 修复部分 MCP 客户端（如使用 rmcp 的客户端）握手失败：`notifications/initialized` 等通知此前被错误返回带 `id` 的 JSON-RPC 响应，违反规范。现对所有通知不再返回响应体，改回 HTTP 202 空响应。
- 优化前台通知文案：允许局域网时不再显示 `0.0.0.0:8000`，改为直接给出可用的完整 MCP 地址并带 `/mcp` 路径，避免用户误填 `0.0.0.0:8000/mcp`。

## 验证

- JVM 单元测试。
- Debug/Release Kotlin 编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

# SOMCP 1.0.15

本发布说明仅包含 `v1.0.14..v1.0.15` 的增量变化。

## 更新内容

- 修复点击启动服务后首页状态未立即刷新为“运行中”的问题。
- 新增本地设置备份与恢复，支持导入、导出 JSON 快照，密钥默认脱敏。
- 修复 xAnSo 在 Android NDK 下的 Windows 专用代码兼容问题。
- 经代码审查撤下未完成且会明文保存凭据的 WebDAV/S3 远程备份。
- 经代码审查撤下会误判正式 APK、触发启动崩溃的原生完整性实验实现，保留稳定的签名摘要校验。
- 清理重复 CI 工作流。

## 验证

- JVM 单元测试。
- Debug Kotlin、Java 与四 ABI 原生编译。
- Release 原生与 Android 构建。
- Release APK 签名与 SHA-256 校验。

- `SOMCP-1.0.15-x86_64.apk`
